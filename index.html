TailRocket

Shadowrocket 自动更新配置：IPv4 Tailscale 最小分流、IPv6 优先、系统 DNS，以及按配置用途适配的自定义规则。

在 Shadowrocket 中进入 配置 → +，直接粘贴下面的 Pages 地址；不需要先下载文件。Pages 暂时不可用时，请使用 README 中对应的 Raw 地址。

推荐入口

  • 黑名单（无广告） — profiles/sr_top500_banlist.conf
  • 黑名单 + 去广告 — profiles/sr_top500_banlist_ad.conf
  • 兼容入口 sr_top500_custom.conf

全部配置

  • lazy.conf · lazy_group.conf
  • sr_top500_banlist.conf · sr_top500_banlist_ad.conf
  • sr_top500_whitelist.conf · sr_top500_whitelist_ad.conf
  • sr_cnip.conf · sr_cnip_ad.conf
  • sr_backcn.conf · sr_backcn_ad.conf
  • sr_direct_banad.conf · sr_proxy_banad.conf
  • sr_adb.conf · sr_ad_only.conf

详细用途、Raw 备用地址、自动更新、Tailscale SSH 边界、故障排查和许可说明请查看 README.md。
